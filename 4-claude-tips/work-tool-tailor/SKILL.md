# work-tool-tailor — 업무 도구 주문서

기성복은 그냥 입고, 안 맞으면 치수를 재서 맞춘다. 치수 재기 = 검토표. 검토표 없이 바로 만들지 않는다.

## 절차

1. **문제 진단 (한 문단)** — 어디서 시간·돈이 새는가? 8칸 중 어디인가:
   시간 관리 · 회의·일정 · 문서·보고 · 계산·견적 · 엑셀·명단 · 진행 관리 · 고객 응대 · 사람·팀.
   사용자가 문제를 못 대면 "지난주 가장 짜증났던 장면 하나"를 묻는다.
2. **기성품 확인** — nondev-thinking.web.app/tools 에 같은 도구가 있으면 링크를 먼저 준다. 그걸로 충분하면 끝.
3. **검토표 제시** (만들기 전에 반드시):
   | # | 기본 기능 | 결정 |
   |---|---|---|
   | 1 | … | [적용 함 / 적용 안 함] |
   기본 기능 8~12개 + 내 상황 질문 3~5개(누가 쓰나, 언제·어떤 기기, 공유 여부, 개인정보 포함 여부, 내보내기 형식).
   "기본값으로 연습판"을 원하면 추천값을 채워 바로 진행.
4. **결정 확정 후 제작** — 기본 규격:
   - 외부 라이브러리 없는 단일 `.html` 1개, 모바일 대응, 다크모드.
   - 저장은 `localStorage` 만(try/catch), CSV 내보내기(UTF-8 BOM, 엑셀 한글 깨짐 방지).
   - 개인정보 입력란은 검토표에서 허락한 것만. 돌봄·상담 기록은 실명 대신 별칭 기본.
   - 지우기 같은 파괴적 버튼은 두 번 눌러 확인.
5. **보고** — 적용한 것 / 적용 안 한 것 / 다음에 추가할 만한 것 3줄.
6. **저장** — `~/Desktop/cysjavis/업무도구/<한글이름>.html` (정본). 공유가 필요하면:
   - 로그인한 동료에게 링크 → Artifact 발행
   - 부서 전체·DB 필요 → Google AI Studio Build(Publish/Share) 또는 appbuild 로 승격

## 목회·돌봄 현장 예시 매핑

| 장면 | 도구 |
|---|---|
| 설교 준비가 밀림 | 목회 시간 기록기(기도·쉼 보호 경고) — 예시: `~/Desktop/cysjavis/매뉴얼/AI도구/업무도구주문사전/목회시간기록기.html` |
