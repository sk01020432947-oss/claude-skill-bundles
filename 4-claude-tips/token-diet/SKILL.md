# token-diet — 지침 문구 토큰 다이어트

근거: 강수진(더프롬프트컴퍼니), 티타임즈TV 2026-09-29 「추론의 강도를 바꿔야 토큰 아낀다」, 2026-09-30 「토큰 까먹는 나쁜 프롬프트 예시, 좋은 프롬프트 예시」.

## 절차

1. 린트를 돌린다: `python3 ~/.claude/skills/token-diet/scripts/lint.py <파일|폴더>`
2. 걸린 항목을 아래 고쳐쓰기 표대로 고친 초안을 보여 준다. 파일은 사용자가 승인한 것만 고친다.
3. 고친 파일에 린트를 다시 돌려 해당 항목이 사라졌는지 확인한다.

**종료 조건:** 요청 범위의 파일에서 `상시읽기`·`과잉작업`이 0건이고, 나머지 항목은 고침·보류 목록으로 보고하면 끝낸다. 한 번에 고치는 스킬은 10개까지로 하고, 남으면 목록만 남긴다.

## 고쳐쓰기 표

| 린트 항목 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 상시읽기 | 매번 수정 전에 architecture.md, database.md, deployment.md를 읽으세요 | 서비스 경계를 바꿀 때만 architecture.md, 스키마를 바꿀 때만 data.md, 배포를 준비할 때만 deployment.md를 읽는다 |
| 부정트리거없음 | 문서를 처리한다 | 법률 계약서 PDF를 검토한다. 일반 요약에는 쓰지 않는다(→ summary 스킬) |
| 시점없음(수동 확인) | 데이터 영속성과 관련된 작업에 사용하세요 | 마이그레이션을 추가·변경하거나 롤아웃을 검토할 때 사용하세요 |
| 과잉작업 | 모든 문제를 단계별로 길게 생각하고 설명해 | 핵심 근거 3개와 결론 1문단만. 중간 과정 보고는 한 줄 |
| 종료조건없음 | (없음) | 검증은 ①시각 일치 ②스크롤 동작 ③모바일 ④한국어 줄바꿈 ⑤빌드 오류, 다섯 개만 하고 끝낸다 |
| 우선순위없음 | 수치를 해석하지 말 것 … 가치 해석을 할 것 | P0 수치 원문 보존 > P1 해석은 별도 '해석' 절에만 |

## 덧붙일 상용 지침 (선택)

- 서브에이전트·새 스킬을 만들기 전에 개수와 이유를 먼저 묻는다.
- 도구 실행 결과는 필요한 줄만 요약해 기록한다.
- 같은 의미의 문장은 반복하지 않는다. 같은 행동을 부르는 중복 항목은 합친다.
- 웹 검색은 공신력 있는 출처만, 필요한 분량만 가져온다.
- 실패하면 그 부분만 고치고 처음부터 다시 하지 않는다.
- 긴 작업은 로그 대신 체크포인트 한 줄과 색인만 남긴다.

`--selftest`로 린트 자체를 점검할 수 있다. 휴리스틱이라 오탐이 있다. 걸린 줄은 사람이 보고 판단한다.
