# ai-license-3day — 대상 맞춤 3일 AI 면허 코스

근거: 혼잡스, 「딱 3일 안에 AI 공부 끝내기 (이 지도 한 장 순서대로만 하세요)」(2026-10-03, https://www.youtube.com/watch?v=6dj6MJwRH2s). 정리본: `~/Desktop/cysjavis/AI동향_검토/AI면허3일_혼잡스_2026-10-09/AI면허3일_정리와_응용.html`

## 입력 (없으면 한 번에 묻는다)
1. 대상: 누구, 몇 명, AI 경험 수준
2. 형식: 90분 특강 / 3일 과정 / 주 1회 3주 소그룹
3. 쓰는 도구: ChatGPT 또는 Claude 중 하나(정거장 ① 원칙: 한 대만)

## 고정 뼈대 (바꾸지 않는다)
| 일차 | 정거장 | 핵심 |
|---|---|---|
| 0 | 출발 전 규칙 | 이론 공부 대신 구독하고 일을 맡긴다 |
| 1 연습장 | ① 차는 한 대만 | 유료 하나, 데스크톱 앱 설치 |
| | ② 진짜 심부름 | 미뤄 둔 조사 → 표 → 한 장 요약 → 엑셀(형식 바꿔 뽑기) |
| | ③ 내 물건 맡기기 | 내 파일 올려 "꼭 확인할 부분만". 브라우저 조작. 결제 비번은 직접 |
| 2 동네 길 | ④ 인수인계서 | 자료 위치·기준·순서·형식 + 잘 된 예시 1개 |
| | ⑤ 세 번 고치기 | 빼기·합치기·더하기. "별로야/다시 해" 금지 |
| | ⑥ 스킬 + 예약 | "이 방식을 스킬로" → "매주 ○요일 ○시에 실행" |
| 3 처음 가는 곳 | ⑦ 미뤄 둔 것 하나 | 기능 하나만(기록+보여주기). 로그인·결제·알림은 나중에 |
| | ⑧ 통째로 맡기기 | 코드는 AI가. 에러는 캡처해서 "원인 찾아 고쳐 줘". 직접 써 보며 고칠 곳 찾기 |
| | ⑨ 링크로 내보내기 | 링크 배포 → 폰에서 열기 → 아는 사람에게만. 실명·전화·주소·계좌 금지 |
| 보너스 | 커넥터 | 드라이브·메일·노션 연결 + ⑥ 스킬과 결합 |
| 다음 날 | 아침에 AI부터 켜기 | "오늘 뭐부터 할까?" |

## 산출물
정거장마다 아래 4가지를 대상 업무 소재로 채운다.
- **미션**: 한 문장 과제(대상의 실제 업무 소재. 예: 교사 → 가정통신문, 교인 시니어 → 주보 광고·병원 안내문 읽기, 사회복지사 → 사례회의 자료 요약)
- **복붙 프롬프트**: 그대로 붙여 쓰는 문장 1~2개
- **통과 기준**: 체크할 수 있는 결과(예: "표에 출처 링크 5개")
- **주의**: 해당 정거장의 개인정보·안전 수칙

마지막에 9칸 체크리스트(본인 체크용)와 수료 기준(9개 중 7개 이상 + ⑨ 필수)을 붙인다. 형식이 특강이면 시간 배분표(90분 예: 규칙 5 · 1일차 25 · 2일차 25 · 3일차 25 · 정리 10)를 붙인다.

## 규칙
- 소재의 개인정보: 교인·학생·내담자 실명, 연락처, 건강·신앙 정보는 예시에 쓰지 않는다. 가명·가짜 데이터로 쓴다.
- 요금·요금제별 기능은 날짜와 함께 "강의 시점 확인 필요"로 표시한다. 수치를 지어내지 않는다.
- 출력은 기본 마크다운. HTML 배포본이나 슬라이드가 필요하면 artifact-design을 먼저 읽고 만들고, 발표자료면 전역 규칙 8(awesome-ai-motion 사용 여부)을 시작 전에 한 번 묻는다.
