# 편집 스타일 DNA — 레퍼런스 영상에서 "내 편집기" 규격 뽑기

출처: 라이프해커,자청 「초등학교 3학년도 할 수 있어요. 딱 한마디만 붙여넣으세요」(youtu.be/7CmGaeKamdc, 2026-10-05). 영상의 "한 마디"는 *"이 영상들을 보고 어떻게 편집하면 좋을지 프롬프트·스킬·모션그래픽을 미리 만들어 놔"*(03:55~04:03)이다. 이 파일은 그 한 마디를 재현 가능한 절차로 바꾼 것이다. SKILL.md의 "If the user handed you a style guide, follow it"에서 쓰는 style guide가 바로 아래 `style_dna.md`다.

## 언제
- "이 스타일로 편집기 만들어 줘", "내 영상 학습해서 앞으로 알아서 편집", "이 유튜버처럼 편집" + 참고 영상 3~10편(영상 속 발언: 10편 03:40, 3~4편 06:53 — 3편부터 시작하고 부족하면 늘린다).

## 1. 수집
- 영상마다 `watch --detail balanced`(프레임+자막). 내 영상이면 원본·완성본 짝이 있으면 둘 다 — 무엇을 잘랐는지가 가장 강한 신호다.
- 원본이 구글 드라이브에 있으면 Drive MCP(`search_files` → `download_file_content`)로 `<videos_dir>`에 내려받는다. 링크만 받았으면 그 파일 하나만.

## 2. 추출 → `<edit>/style_dna.md`
항목마다 **관찰값 + 근거(영상 번호, mm:ss)**. 못 본 항목은 "관찰 안 됨"으로 비워 둔다(추측 금지).

| 층 | 항목 |
|---|---|
| 리듬 | 평균 컷 길이, 무음·숨·말실수 처리, 점프컷/펀치인 빈도 |
| 자막 | 위치(MarginV), 글꼴·굵기·크기, 글자색/외곽선/박스, 강조색과 강조 규칙, 줄당 어절 수 |
| 화면 | 얼굴 위치·크기, 확대 시점, 비율(9:16/16:9) |
| B-roll | 빈도(분당), 종류(스크린샷·SNS 캡처·스톡·생성), 길이, 전환 |
| 모션 | 제목 카드, 숫자·키워드 강조, 화면 상단 고정 타이틀 |
| 소리 | 효과음 쓰는 순간, 배경음 장르·덕킹 레벨 |
| 구조 | 오프닝 훅(첫 3초), 아우트로(내 채널 것만), 총 길이 |

## 3. 확인 1회
DNA 표를 보여 주고 승인받는다(Hard Rule 11). 승인 뒤에는 새 원본마다 이 파일을 style guide로 읽고 바로 편집한다.

## 4. 교정 루프 (영상 04:13~04:27)
사용자가 "이게 빠졌다"고 하면 고치고, 같은 내용을 `style_dna.md` 끝 `## 교정 기록`에 날짜와 함께 한 줄 추가한다. 다음 편집은 교정 기록까지 읽는다. 이 누적이 "학습"의 실체다.

## 경계
- 남의 영상: 구조·리듬·수치만 빌린다. 그 사람의 영상 클립·음악·로고·아우트로·말버릇 자막은 쓰지 않는다.
- B-roll 출처 우선순위: 내 촬영 > Pexels/Pixabay(라이선스 확인) > `media-gen` 생성. 클립마다 출처를 `<edit>/broll_sources.md`에 적는다. SNS 캡처는 공개 게시물이라도 작성자 표기.
- 목소리: 본인·동의받은 음성만(`voicebox-local-tts`, `voice-clone-elevenlabs`).
- 얼굴 없는 영상·자동 B-roll 영상은 출고 전 `video-verify`(영상 속 제작자도 확인하지 않은 결과물을 보여 줬다, 04:31).
