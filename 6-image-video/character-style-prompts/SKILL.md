# 캐릭터 스타일 프롬프트 아카이브

원본: https://revfactory.github.io/character-comic/ · 로컬 갤러리: `~/Documents/character-comic/index.html`
설명서: `~/Desktop/cysjavis/매뉴얼/영상_이미지도구/캐릭터스타일_프롬프트아카이브_설명서.html`

## 1. 프롬프트 찾기

```bash
python3 ~/.claude/skills/character-style-prompts/find.py              # 110개 목록
python3 ~/.claude/skills/character-style-prompts/find.py 낙서         # 카테고리 목록
python3 ~/.claude/skills/character-style-prompts/find.py 낙서 3       # 전문
python3 ~/.claude/skills/character-style-prompts/find.py -s 도장      # 검색
```

카테고리 키: 낙서 graffiti · 질감 texture · 변주 diversity · 유행 meme · 시대 era · 기호 sign · 도해 diagram · 기계 machine · 거리 street · 무대 stage · 게임 game

## 2. 쓰는 법

1. 사용자가 원하는 느낌을 듣고 후보 2~3개를 제목으로 제시한다. 막연하면 카테고리 설명(desc)으로 좁힌다.
2. 고른 프롬프트 전문을 **그대로** 보여 준다. 임의 요약 금지. 사용자는 이 문장을 사진과 함께 이미지 모델(ChatGPT·Gemini·Codex `image_generation`·fal.ai)에 붙여 넣는다.
3. 생성까지 요청받으면 `media-gen-image` 스킬에 사진 + 프롬프트를 넘긴다. 첫 결과가 양식을 벗어나면 마지막 문단에 금지 조건("…은 넣지 않는다")을 한 줄 추가해 재시도한다.

## 3. 변형·확장

프롬프트는 6슬롯 구조다. 바꿀 슬롯만 바꾸고 나머지는 원문을 유지한다.

| 슬롯 | 원문 예 | 바꾸는 법 |
|---|---|---|
| ① 지시+대상+매체 | 첨부 사진 속 인물을 …로 다시 그려줘 | 대상(인물→건물·반려견·사물·장면)과 매체 교체 |
| ② 신원 유지 | 헤어스타일·얼굴형·옷차림은 남긴다 | 대상에 맞는 "사진에서 읽히는 것"으로 교체. 특징 이름(안경·수염)은 절대 적지 않음 |
| ③ 재료·도구·선 | 검은 볼펜, 흔들리고 겹치는 선 | 매체가 실제로 남기는 물리 흔적을 눈에 보이는 대로 적음. 상품명·작가명 금지 |
| ④ 요소 단순화 규칙 | 눈은 점 두 개, 코는 선 하나 | 대상의 핵심 부위별 규칙으로 교체 |
| ⑤ 품질 방향·금지 | 전문가 낙서가 아니라 진짜 아이 그림처럼 | "…처럼 보이면 안 된다" 형태의 반례 1~2개 |
| ⑥ 구도·배경·글자 | 흰 배경, 한 명, 전신, 글자 없음 | 인원·앵글·배경·글자 허용 여부 |

새 시리즈(10개)를 지을 때는 한 축(재료 / 시대·매체 / 기계 오류 / 표면 / 무대 / 화면)을 고정하고 그 축 안에서 열 가지 실물을 고른다. 자세한 예시와 다른 영역(사물·장소·동물·음식·성경 장면·데이터) 템플릿은 `extend.md`.
