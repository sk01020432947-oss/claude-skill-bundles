# 확장 템플릿 — 캐릭터 밖으로

## 범용 골격(6슬롯)

```
첨부 사진 속 [대상]을 [매체·상황]로 바꿔줘.

[대상]임을 알아볼 수 있도록 [사진에서 읽히는 형태 특징 2~4개]는 남긴다. [세부 묘사 수준] 은 과감하게 생략한다.

[재료·도구]로 [물리적 흔적: 선·면·질감·오류]처럼 표현한다. [흔적의 불완전함을 허용하는 문장].

[핵심 부위 A]는 [규칙], [B]는 [규칙], [C]는 [규칙]으로 단순하게 처리한다.

[반례: ~처럼 보이면 안 된다]. [지향: 진짜 ~처럼 보여야 한다].

[구도: 인원·앵글·크기]. [배경]. [글자·장식·그림자·테두리 허용/금지].
```

## 영역별 ②슬롯(무엇을 남길지) 치환표

| 대상 | 남길 것(사진에서 읽히는 것) | 절대 이름 붙이지 말 것 |
|---|---|---|
| 건물·교회·가게 | 지붕 실루엣, 창 배열 리듬, 출입구 위치, 층수 | 십자가·간판 글씨 같은 개별 부착물 |
| 반려동물 | 귀 모양, 털 길이 덩어리감, 체형, 꼬리 자세 | 품종명, 목줄·옷 |
| 사물·제품 | 실루엣, 주요 분할선, 손잡이·버튼 위치 | 브랜드·로고 |
| 음식 | 그릇 형태, 덩어리 배치, 높이감 | 메뉴명 |
| 풍경·장소 | 지평선 높이, 큰 덩어리 3개의 배치 | 지명 |
| 여러 사람(가족·팀) | 인원수, 키 순서, 서 있는 간격, 각자의 머리 모양 | 이름·관계 |
| 성경·역사 장면(사진 없음) | "첨부 사진" 대신 장면 서술 1문장 + 인물 수·동작 | 특정 화가 화풍명 |
| 데이터·개념 | 단계 수, 흐름 방향, 덩어리 크기 비례 | 실제 수치·라벨 글자 |

## 완성 예시

### 교회 건물 → 청사진 설계 도면 (도해 06 변형)
```
첨부 사진 속 건물을 옛 청사진 설계 도면처럼 바꿔줘.

이 건물임을 알아볼 수 있도록 지붕의 실루엣, 창이 반복되는 리듬, 정면 출입구의 위치와 층수는 남긴다. 벽 재질, 색, 주변 나무와 차는 모두 지운다.

짙은 파란 종이 위에 흰 잉크 선으로 그린 복사 도면이다. 선 굵기는 거의 일정하고 곡선도 자를 대고 그은 듯 정확하다. 종이 가장자리는 옅게 바래고 접힌 자국이 한두 줄 지난다.

정면 입면도를 화면 가운데에 크게 두고, 그 옆에 평면도 조각 하나를 작게 붙인다. 두 그림은 가는 지시선으로 잇되 치수 숫자와 글자는 달지 않는다.

관광 엽서나 3D 렌더링처럼 보이면 안 된다. 실제 설계 사무소에서 복사한 도면처럼 담담해야 한다.

건물 한 채만 배치하고 사람, 하늘, 그림자, 테두리, 제목 칸은 넣지 않는다.
```

### 반려견 → 펠트 손바느질 인형 (질감 05 변형)
```
첨부 사진 속 개를 펠트 천으로 손바느질해 만든 인형으로 바꿔줘.

이 개임을 알아볼 수 있도록 귀가 서 있는지 접혀 있는지, 털 덩어리의 길이감, 몸통과 다리의 비례, 꼬리의 자세는 남긴다. 실제 털 한 올과 눈의 세부는 생략한다.

두꺼운 펠트를 가위로 오려 겹치고 굵은 실로 홈질한 흔적이 보인다. 바늘땀은 간격이 고르지 않고 실 끝이 삐져나온 곳이 있다. 천의 보풀과 절단면의 도톰한 두께가 드러난다.

눈은 검은 단추 두 개, 코는 작은 삼각형 펠트 조각, 입은 실 한 줄로 만든다. 다리는 짧고 통통한 원통 네 개로 단순화한다.

공장에서 만든 봉제 인형이나 매끈한 3D 렌더링처럼 보이면 안 된다. 손으로 처음 만들어 본 사람의 인형처럼 조금 어설퍼야 한다.

밝은 나무 탁자 위에 인형 하나만 정면으로 앉혀 놓고 촬영한 사진처럼 만든다. 다른 소품, 글자, 강한 그림자는 넣지 않는다.
```

### 성경 장면 → 그림자 인형극 (무대 01 변형, 사진 없음)
```
갈릴리 호수의 배 위에서 잠든 한 사람과 폭풍에 놀란 제자 네 명이 있는 장면을 그림자 인형극 무대로 만들어줘.

인물은 모두 검은 종이를 오려 만든 납작한 실루엣이며 관절마다 가는 막대와 리벳이 보인다. 얼굴 세부는 없고 머리 모양과 옷자락의 윤곽, 팔의 각도만으로 누가 잠들었고 누가 놀랐는지 읽혀야 한다.

뒤에서 비추는 따뜻한 등불 빛이 얇은 천 스크린을 통과해 가장자리가 부드럽게 번진다. 파도는 겹쳐 세운 종이 물결 세 겹으로 만들고 물결의 결은 뚫린 무늬로 표현한다.

무대 양옆에 검은 커튼 실루엣이 조금 보이고 스크린은 화면의 대부분을 차지한다.

디지털 벡터 일러스트나 영화 장면처럼 보이면 안 된다. 실제 종이 인형과 천과 등불로 만든 무대를 정면에서 찍은 사진처럼 보여야 한다.

글자, 자막, 테두리는 넣지 않는다.
```

### 설교 3단 구조 → 가구 조립 설명서 (도해 01 변형, 개념 도해)
```
세 단계로 이어지는 하나의 과정을 조립식 가구 설명서 그림처럼 그려줘. 단계는 아래에서 위로 쌓이는 상자 세 개이며, 각 상자는 이전 상자 위에 끼워진다.

색을 쓰지 않는다. 굵기가 일정한 검은 윤곽선과 흰 면만 사용하고 명암과 무늬는 지운다.

상자 세 개를 공중에 조금씩 띄워 놓고, 어느 것이 어디에 들어가는지 가는 점선과 화살표로 잇는다. 상자 사이에 나사 두어 개를 함께 띄운다. 상자 옆에는 조립하는 손 하나를 설명서 그림 특유의 단순한 형태로 넣는다.

상자 크기는 아래가 가장 크고 위로 갈수록 작아져 비례가 한눈에 읽힌다.

인포그래픽이나 프레젠테이션 도형처럼 보이면 안 된다. 실제 가구 상자에 든 종이 설명서처럼 담담해야 한다.

배경은 흰색, 숫자·글자·단계 표시·테두리는 넣지 않는다.
```

## 새 시리즈 10개 짓는 법

1. 축 하나 고정: 재료(질감) / 시대·매체(시대) / 기계 오류(기계) / 도시 표면(거리) / 무대 장치(무대) / 화면 규격(게임) / 설명 그림(도해) / 기호 압축(기호).
2. 그 축 안에서 실제로 존재하는 사물·인쇄물·기계 열 가지를 나열한다(상품명 금지, "그 화면이 실제로 어떻게 생겼는지"만).
3. 각 항목마다 ③슬롯(물리 흔적)을 3문장 이상 관찰 문장으로 쓴다. 이 부분이 시리즈의 품질을 결정한다.
4. ②·⑥슬롯은 시리즈 안에서 문장을 통일한다(일관성 = 시리즈감).
5. 같은 원본 사진 한 장으로 10개를 모두 뽑아 나란히 두고, 양식이 안 나온 것은 ⑤슬롯 금지 문장을 추가해 다시 뽑는다.
