# photo-retouch

이미지를 받아 전문 리터처처럼 **진단 → 보정 → 보고** 3단계로 처리한다.
새 도구를 만들지 않는다 — 로컬 Pillow와 기존 media-gen 스킬로 라우팅하는 워크플로 계층이다.

## 1. 진단

원본을 Read로 열어 육안 점검 + Python(Pillow)으로 히스토그램·해상도·EXIF 확인.
항목별 판정: 색 균형 / 대비·채도 / 노이즈 / 선명도 / 조명(섀도·하이라이트) / 구도·크롭 / 잡티.
문제 항목만 사용자에게 한 줄씩 보고 후 진행(승인 대기 없이 계속).

## 2. 보정 경로 선택 (비용 사다리 — 위에서부터)

| 경로 | 도구 | 비용 | 커버 범위 |
|------|------|------|----------|
| A. 로컬 보정 | Python + Pillow (`ImageEnhance`, `ImageFilter`, autocontrast, unsharp mask) | 무료 | 색·대비·채도·샤프닝·노이즈(약)·크롭·리사이즈 |
| B. 생성형 편집 | `[[media-gen-edit]]` (nano-banana-pro/edit) | 유료 → `[[cost-preview-confirm]]` | 잡티 제거, 배경 교체, 조명 재구성, 크리에이티브 편집(글로우·파스텔·네온), 원근 보정 |
| C. 업스케일 | `[[media-gen-upscale]]` | 유료 | 해상도·디테일 복원 |

A로 충분하면 A만. B/C는 A가 못 하는 요구가 명시됐을 때만.
인물 사진에서 B 사용 시 media-gen-edit의 **정체성 보존** 규칙을 그대로 따른다.

## 3. 스타일 프리셋

요청 시 적용, 미지정이면 natural:

- **natural** — 색 균형·미세 대비만, 원본 존중
- **cinematic** — 낮은 채도 + 틸/오렌지 톤 + 강한 명암
- **vibrant** — 채도·대비 상향
- **minimalist** — 채도 하향 + 밝은 톤 + 여백 크롭
- **portrait** — 피부톤 보존 우선, 배경만 처리
- **product** — 흰 배경 정리 + 강한 선명도 + 중앙 구도

## 4. 출력 계약

원본과 같은 폴더에 `<원본이름>-retouched.<ext>` 저장(원본 절대 덮어쓰지 않음).
SendUserFile로 결과 전달 + 개선 목록(적용 항목·수치·사용 경로 A/B/C)을 표로 보고.
비교가 필요하면 전/후 나란히 붙인 비교 이미지 1장 추가 생성.
