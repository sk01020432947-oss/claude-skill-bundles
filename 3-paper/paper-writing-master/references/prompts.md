# 단계별 프롬프트·템플릿

> 공통 규칙: ① 사용자가 준 자료만 근거 ② 자료 밖 문헌 금지(필요하면 검색 도구로 찾아 링크 첨부) ③ 문장마다 (저자, 연도) ④ 끝에 근거 위치표와 품질 게이트.

## 1. 키워드 설계 (1단계)
```
관심사: [ ]. 연구 대상 후보 5개와 각 대상의 '문제거리'(종속변수 후보) 5개를 제시하고,
대상×문제거리 키워드 10개를 한/영으로, 각 키워드의 상위 개념 검색어를 함께 제시하라. 문헌 인용 금지.
```

## 2. 대·도·방 필터 (2단계)
```
아래 논문 제목 목록에서 각 제목의 대상/도구(변수)/방법을 표로 추출하고,
내 연구(대상 [ ], 종속변수 [ ])와의 관련도를 상·중·하로 매겨라. 판단 불가는 '?'로.
```

## 3. 정리표 → 연구문제 (3단계)
```
아래 선행연구 정리표만 근거로 (1) 동향 (2) 저자가 인정한 한계 (3) 결과 불일치를 표로 정리하고
각 항목의 출처 행을 표시하라. 이어서 공백을 메우는 연구문제 3개와 차별성 유형
(변수 확장/매개·조절/대상 희소성/관점 전환/방법 개선/불일치 규명)을 제시하라.
```

## 4. 설계 점검 (4단계)
```
연구문제·가설·대상·측정도구·분석법을 대도방 표로 만들고, 1:1로 맞지 않는 곳과
더 단순한 대안 모형을 제시하라. 각 경로(X→M, M→Y, X→Y)에 필요한 근거 문헌 유형을 적어라.
```

## 5. 문단 단위 뼈대 (5단계)
```
5장 구조로 장-절-문단 목차를 만들라. 문단마다: 한 문장 메시지 | 필요한 근거(Zotero 키 또는 '필요') | 다음 문단 연결어.
```

## 6. 서론 구획 초안 (6단계)
```
역할: [전공] 학술지 편집위원. 자료: 첨부 PDF/메타데이터만.
과제: 서론의 '선행연구 동향 → 한계' 4문단. 두괄식, 문장마다 (저자, 연도),
연구자 주관 문장 금지, 마지막 문단은 '한계'로 끝낼 것. 끝에 인용 근거 위치표.
```

## 7. 이론적 배경 재구성 (7단계)
```
아래 학자별 정의를 '불일치 지점 → 분류 기준 → 정리' 순으로 재구성하고, 본 연구의 학술적 정의를 제안하라.
3장 조작적 정의(측정도구 [ ])와 맞는지 확인하라.
```

## 8. 결과 서술 (10단계)
```
아래 결과표의 수치만 근거로 APA 7판 결과 문장을 써라. 원인 해석·제언 금지.
유의한 계수, 방향, 효과크기, 모형 설명력 변화를 포함하라.
```

## 9. 논의 (11단계)
```
결과 요약 + 아래 선행연구 결과와의 공통점·차이점을 표로 만들고, 차이의 가능한 이유를
'표본/측정/맥락/방법' 범주로 제시하라(추정은 '가능성'으로 표현). 시사점은 연구 목적 수위 [기초자료/전략] 안에서만.
```

## 10. 제목·초록 (12단계)
```
제목 후보 5개(대상+변수+관계 구조, 부제에 매개·조절 표기). 국문 초록 250자 내외:
배경·목적→대상→도구→방법→결과→의의. 영문 초록은 국문과 정보 일치.
```

## 11. 심사 대비 (14단계)
```
이 논문으로 심사위원 예상질문 20개를 Why/How/What/So what으로 나누고,
각 질문에 논문 본문 근거 위치와 30초 답변 초안을 붙여라. 답변 불가 질문은 '보완 필요'로 표시.
```
```
수정대비표: 지적자 | 지적 내용 | 수정 전(쪽) | 수정 후(쪽) | 반영/부분반영/미반영 사유
```

## 12. 연구노트·AI 사용 기록 (0·13단계)
```
날짜 | 결정 | 근거 | 파일·버전 | AI 도구·버전·사용 범위 | 검증 방법
```
AI 사용 공개 문구 예: "본 연구는 선행연구 요약과 문장 교정에 생성형 AI(도구명, 버전)를 보조적으로 활용하였으며, 모든 인용과 분석 결과는 연구자가 원문과 원자료로 확인하였다." (투고처 규정 우선)
