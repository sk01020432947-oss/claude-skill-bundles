# 산출물 품질 게이트

모든 산출물 끝에 아래 5줄을 붙인다(해당 없는 항목은 '해당 없음').

```
[정합성] 연구문제–가설–대상–도구–분석법 매칭: OK / 불일치 지점: …
[근거] 주장 문장 수: n (0이 목표) / 근거 없는 단정: …
[인용] 실존 확인 n건 / [확인 필요] n건 (목록)
[용어] 핵심 용어 통일 여부: … (혼용 발견 시 표기)
[사용자 몫] 직접 재작성할 문장·결정할 사항: …
```

## 단계별 통과 기준
| 단계 | 통과 기준 | 실패 시 되돌아갈 곳 |
|---|---|---|
| 연구문제 | 필요성 문단이 인용만으로 성립 | 2 선행연구 |
| 설계 | 가설마다 분석법 1개, 변수마다 측정도구 1개 | 3 연구문제 |
| 뼈대 | 문단 메시지만 읽어도 목적이 보임 | 4 설계 |
| 서론 | 마지막 문단이 연구문제로 닫힘, 한계→필요성 다리 문장 존재 | 5 뼈대 |
| 이론 | 2장 정의 = 3장 조작적 정의 = 4장 변수명 | 5 뼈대 |
| 결과 | 결과 문장의 모든 수치가 표와 일치 | 10 분석 |
| 결론 | 연구문제 수 = 논의 문단 수, 시사점이 목적 수위 안 | 6 서론 |
| 마무리 | 본문 인용 ↔ 참고문헌 교차율 100%, 양식 1종 | 12 |
| 윤리 | 설명 못 하는 문장 0, AI 사용 기록 존재 | 13 |

## 금지 패턴 탐지
- "~라고 생각된다/~해야 할 것이다" 류 연구자 주장 문장이 서론·이론에 등장
- 선행연구 나열("A(2020)는 …했다. B(2021)는 …했다.")이 3문장 이상 연속 → 카테고리화
- 기법 이름이 연구문제보다 먼저 결정됨
- 결론에 서론에 없던 새 개념·새 목적 등장
- 존재 확인 안 된 문헌, DOI·쪽수 없는 직접 인용
- AI 문장의 마크다운 기호(**, #, -) 잔재
