## 1. 지도자용 진단표 — "어디서 막혔는가"

학생이 "논문이 안 써져요"라고 할 때, 증상으로 단계를 진단하고 해당 차시로 보낸다.

| 증상 | 진짜 원인 | 처방 차시 |
|---|---|---|
| 주제를 몇 달째 못 정함 | 완벽한 주제를 먼저 찾으려 함 / 대상과 주제를 혼동 | 3·4차시 |
| 선행연구를 읽기만 하고 진도가 없음 | '공부' 모드, 정독, 조사의 늪 | 4·5차시 |
| "선행연구가 없어요" | 키워드가 너무 좁음, 거짓 공백 | 4차시 |
| 서론이 장황하고 배경만 길다 | 뼈대 없이 서론부터 씀, 한계→필요성 다리 부재 | 8·9차시 |
| 지도교수가 매번 다른 말을 함 | 스타일 미파악, 설계 합의 부재 | 2·15차시 |
| 통계는 돌렸는데 해석을 못 함 | SW 유저 단계, 원리 이해 부족 | 11차시 |
| 결과가 상식과 반대로 나옴 | 데이터 정제·억제효과·설계 문제 | 11차시 |
| 결론에 쓸 말이 없음 | 서론에서 목적·범위를 정하지 않음 | 13차시 |
| AI로 썼는데 내용을 설명 못 함 | 연구 역량 < AI 의존, '좀비 논문' | 14차시 |
| 심사가 두려움 | 내 논문 이해도 부족(자신감은 이해에서 나옴) | 15차시 |

## 차시 1 — 오리엔테이션: 논문이란 무엇인가

**학습목표**: 논문과 보고서·에세이의 차이를 설명하고, 연구자의 정체성을 세운다.

**핵심 메시지**
- "대학원은 공부하러 온 게 아니라 연구하러 온 곳이다." ([23.12.13](https://youtu.be/x0TXu6f4f1o), [26.07.30](https://youtu.be/_3RtUdN2TZk))
- "논문은 쓰는 게 아니고 짠다." ([23.08.31](https://youtu.be/S-ehp0rYJ9Q))
- 사회과학은 '발견 지향'이 아니라 측정하고 관계를 확인하는 **'경험 지향'** 학문이다. ([23.02.21](https://youtu.be/0VlogNKtvzo))

**강의 내용**
1. 연구(Research) = 내가 이해하기 위한 콘텐츠 생산, 논문(Paper) = 독자가 이해하도록 틀에 담는 작업. ([20.02.18](https://youtu.be/j9M8rYQ70q0), [23.12.11](https://youtu.be/6pXEY7ft6NA))
2. 논문의 가치는 페이지 수가 아니라 Why(필요성)·How(방법)·Significance(기여)로 결정된다. ([24.03.15](https://youtu.be/vOdHz4oKpsM), [24.09.10](https://youtu.be/91MmOQtDn54))
3. 논문 = 가설을 학술적 근거로 객관적으로 '증명'하는 과정. 연역적으로 문제를 제기하고 귀납적으로 푼다. ([18.11.16](https://youtu.be/NnplX4dg_w0))
4. 의존의 함정: 불안해서 컨설팅·선배·AI에 결과물을 맡기면 역량이 생기지 않고 심사에서 무너진다. ([20.04.11](https://youtu.be/I_YjRKtZzgQ), [24.10.29](https://youtu.be/3tcH84LPrNw))
5. 건강과 지속성: 연구는 단거리가 아니다. 스트레스가 건강을 해칠 정도면 건강이 우선. ([19.04.09](https://youtu.be/b2MevrO7x8o), [24.10.07](https://youtu.be/dkV022I5mfE))

**실습**: 각자 관심사를 한 문장으로 쓰고, "이것은 보고서인가 논문인가?"를 짝과 토론.
**체크리스트**: □ 연구와 페이퍼의 차이를 말로 설명할 수 있다 □ 내 논문의 1차 목표(학과 기준 통과)를 안다 ([18.11.06](https://youtu.be/KqEs5prxN2s))
**과제**: 학교 논문 작성 매뉴얼 확보, 학위 요건(학술지 게재 등) 확인.

## 차시 2 — 지도교수와 학교의 '틀' 읽기, 연구노트

**학습목표**: 지도교수 스타일을 분석하고, 연구 기록 체계를 만든다.

**핵심 메시지**: "논문은 매뉴얼에 맞고 교수님 스타일에 맞춰 들고 가야 한다. 그게 교수님이 보기 편하게 만드는 기본이다." ([19.03.09](https://youtu.be/hz1UCGt-zqo))

**강의 내용**
1. RISS에서 지도교수의 최근 지도 논문 3~5편을 찾아 목차, 분량, 변수 구성, 방법론, 문단 흐름을 표로 비교. ([18.11.07](https://youtu.be/mtG2fq8BLZg), [19.07.03](https://youtu.be/f_Qs2UG3Eyk), [20.12.11](https://youtu.be/dGO4FL5uSlk))
2. 지도교수와의 소통: 메일로 요약을 먼저 보내 '워밍업', 대면은 1~3분 요약으로. 모호한 지도는 "몇 쪽 몇 줄을 어떤 방향으로"라고 구체화 요청. ([22.04.28](https://youtu.be/d0GeRB07s2s), [23.03.23](https://youtu.be/3csj3T6mAH4))
3. 지도교수와 의견이 다를 때: 감정이 아니라 근거로. 지도 갈등을 자기 무능으로 해석하지 않는다. ([23.09.12](https://youtu.be/_kvJXbTLzhY), [23.11.22](https://youtu.be/tAqZhBFNP6w))
4. 연구노트·원자료·버전 이력은 나중에 표절·AI 의혹의 방패가 된다. ([26.10.19](https://youtu.be/astMycrVGC8))

**실습**: 지도교수 논문 비교표 작성(항목: 제목 구조, 장 구성, 대상, 변수 수, 분석법, 분량).
**체크리스트**: □ 지도교수 스타일 3줄 요약 □ 연구노트 시작(날짜·결정·근거·파일명)
**[보강] 연구노트 양식**: `날짜 | 오늘 결정한 것 | 근거(문헌/데이터) | 바뀐 파일·버전 | AI 사용 여부와 범위`

## 차시 3 — 주제 탐색: 넓게 시작해서 '점'으로

**학습목표**: 관심사를 '대상 × 문제거리' 키워드로 바꾸고 범위를 정한다.

**핵심 메시지**: "연구 논문의 주제는 하나의 점이다." ([15.01.01](https://youtu.be/mFJvUtNECBs)) / "논문은 개인적인 관심사를 학계로 옮겨가는 과정이다." ([17.02.23](https://youtu.be/ZhJTgOFIuCg))

**강의 내용**
1. 키워드 공식: **연구 대상 + 그 대상이 가진 문제거리**. ([26.01.20](https://youtu.be/2-VlmJpXpqM))
2. 대상에 갇히지 말 것: 대상은 모형의 '선정 대상'일 뿐, 논리 근거는 상위 개념의 선행연구에서 찾는다(예: '보육교사' → '교사', '감정노동자'). ([19.07.10](https://youtu.be/FhWsMxJnZQM))
3. 사회 이슈·개인 경험 → 학술 문제로 전환하지 않으면 보고서. ([21.06.03](https://youtu.be/bTC-pm_R6pc), [26.03.03](https://youtu.be/Y_UZUkXeJw4))
4. 너무 큰 주제 금지: 다 풀려 하지 말고 후속연구로 넘기는 절제. ([24.08.23](https://youtu.be/cxtVt-yjpFo), [24.03.04](https://youtu.be/vkhEL0Jxbd0))
5. 주제와 방법은 동시에 고려한다(데이터를 구할 수 있는가?). ([22.05.05](https://youtu.be/wQuNmW2eZ-Q))

**실습**: 관심사 → 키워드 조합 5개 → RISS·구글 스칼라 검색 건수 기록 → 너무 적으면 상위 개념으로, 너무 많으면 문제거리를 좁힌다.
**AI 실습 [보강 프롬프트]**
```
나는 [전공] 석사과정생이고 관심사는 [관심사]다. 연구 대상 후보와 그 대상의 '문제거리'(종속변수 후보)를
각각 5개씩 제시하고, 대상×문제거리 조합 키워드 10개를 한국어·영어로 만들어라.
각 조합의 상위 개념 키워드도 함께 적어라. 실제 논문은 인용하지 마라(검색은 내가 직접 한다).
```
**주의**: AI에게 주제를 통째로 맡기면 논리 없는 '좀비 논문'이 된다. ([25.04.25](https://youtu.be/C_WaFTp5M94))
**과제**: 키워드 3세트 확정, 각 세트로 논문 20편 이상 목록 확보.

## 차시 4 — 선행연구 검색과 '대·도·방' 필터링

**학습목표**: 선행연구를 빨리, 많이 훑어 필요한 것만 집어낸다.

**핵심 메시지**: "제목에서 대도방을 찾으면 논문의 50%는 감을 잡는다." ([22.03.30](https://youtu.be/nqxAXEtIJ_w)) / "선행연구 조사는 족집게처럼 필요한 콘텐츠만 탁탁 집어 오는 것." ([23.04.27](https://youtu.be/drryUIIAAFg))

**강의 내용**
1. 3단 필터: 제목(대상·도구·방법) → 초록(변수 관계·목적) → 최신성·학술지 수준(최근 3~10년). ([23.08.17](https://youtu.be/bWBtqNoMBKg), [18.12.12](https://youtu.be/t-NXT9y04Bs))
2. 목적별 독법: 논리 구성 → 초록·서론·결론 / 설계 → 연구방법 / 개념 → 이론적 배경. 상세 독해 순서: 방법 → 결론 → 서론 → 이론. ([23.08.17](https://youtu.be/bWBtqNoMBKg), [25.03.14](https://youtu.be/Q_ac4s_4o9s))
3. 정독 금지, 구조를 보며 3~4회 반복 훑기. ([24.02.20](https://youtu.be/5nTbO_Ku3nM))
4. 검색처: RISS(학위논문), KCI·DBpia·KISS(학술지), 구글 스칼라(국외), 대학 전자도서관. ([22.12.30](https://youtu.be/qkUmuhpiWxU))
5. **Zotero를 연구의 허브로**: 전자도서관에서 RIS/BibTeX 내보내기 → 컬렉션 관리 → 인용 자동화. ([25.04.04](https://youtu.be/QZiba5zD__g), [25.05.31](https://youtu.be/uom_Vc4COj8), [26.05.10](https://youtu.be/6jSaxKBjZw4))
6. AI 탐색 도구: Consensus·SciSpace(검색·요약), Research Rabbit(인용망 확장), NotebookLM(내 PDF 질의·마인드맵). ([24.01.18](https://youtu.be/czH9WYSwLD4), [26.04.14](https://youtu.be/5x3hCiCMrjk))

**실습**: 키워드 1세트로 50편 제목 스캔 → 대도방 표시 → 20편 초록 확인 → 10편 Zotero 등록.
**주의**: AI가 준 참고문헌은 RISS·구글 스칼라·DOI로 실존 확인. 용어만 다른 기존 연구를 못 찾아 생기는 **거짓 공백**. ([23.03.06](https://youtu.be/ZiUaelKv5CA), [26.09.29](https://youtu.be/_dBlstZYg30))
**체크리스트**: □ Zotero 컬렉션 생성 □ 핵심 문헌 10편 이상 □ AI 제시 문헌 실존 확인 완료

## 차시 5 — 선행연구 정리표와 연구문제 도출

**학습목표**: 엑셀 정리표에서 동향과 한계를 뽑아 연구문제·가설을 만든다.

**핵심 메시지**: "선행연구 정리의 최종 결과물은 동향을 파악하고, 한계를 발견하고, 그 한계를 극복하는 연구문제를 던지는 것." ([15.01.01](https://youtu.be/Uju-fwXYKMw))

**강의 내용**
1. 엑셀 정리표 열: 연구자 | 연도 | 학술지 | 대상 | 독립·매개·조절·종속변수 | 측정도구 | 분석방법 | 주요 결과 | 한계 | 후속연구 제안. 핵심 30~40편. ([18.11.30](https://youtu.be/AhFJikiJrD8), [18.12.12](https://youtu.be/t-NXT9y04Bs), [23.08.16](https://youtu.be/4TI2AEockts))
