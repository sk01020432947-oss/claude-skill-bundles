# 분석 방법 선택표 (논준모 영상 종합)

| 연구 질문의 형태 | 1순위 방법 | 조건·대안 | 도구 |
|---|---|---|---|
| 두 집단 차이 | 독립 t-test | 비정규·소표본 → Mann-Whitney | jamovi, SPSS, R |
| 세 집단 이상 차이 | 일원 ANOVA + 사후검정 | 등분산 위배 → Welch | 同 |
| 사전-사후 차이(실험) | 사전 동질 → RM ANOVA / 사전 이질 → ANCOVA | 통제집단 없는 설계는 결함 | 同 |
| X가 Y에 미치는 영향 | 다중회귀 | 통제변수 있으면 위계적 회귀(통제변수 1단계) | 同 |
| 매개효과 | PROCESS Model 4 부트스트래핑 | 잠재변수 다수 → SEM 간접효과 | SPSS PROCESS, jamovi medmod, R lavaan |
| 조절효과 | 평균중심화 후 상호작용항 회귀(PROCESS Model 1) | 범주형 조절변수 → 다집단 분석 | 同 |
| 조절된 매개 | PROCESS Model 7/14 등 | 이론적 근거로 모형 번호 선택 | 同 |
| 잠재변수 구조·이론 검증 | CB-SEM (CFA → 구조모형) | 정규성·표본 충분 | AMOS, R lavaan, jamovi SEMLj |
| 예측·탐색, 비정규, 소표본, 형성지표 | PLS-SEM | 2차 요인 구조 | SmartPLS |
| 척도 개발 | 문헌·FGI·델파이 → EFA(병렬분석으로 요인 수) → CFA → 신뢰도 | 표본 분할(EFA/CFA) | jamovi, R psych |
| 전문가 우선순위 | AHP(쌍대비교, CR≤.1) | 후보 도출은 FGI·델파이 | Excel, 전용 SW |
| 요구도 분석 | IPA, Borich, Locus for Focus(IPA+Borich) | 사전 중요도·현재 수준 문항 | Excel |
| 위계 자료(학생-학급, 아동-기관) | 위계선형모형(HLM/MLM) | 집단 수 충분 | R lme4, HLM |
| 패널·종단 자료 | 패널회귀(고정/확률효과), 잠재성장모형 | 공개 패널데이터 활용 | Stata, R |
| 질적 — 체험의 본질 | 현상학: 지오르기(심리학적 변환), 콜라이지(참여자 확인), 반매넌(해석학적·위치성) | 후설(기술) vs 하이데거(해석) 입장 명시 | 클로바노트, NVivo, Taguette, QCoder |
| 질적 — 과정·이론 생성 | 근거이론(개방→축→선택 코딩) | GPTs 코딩 보조 후 연구자 검증 | 同 |
| 혼합 | 탐색적 순차(질적→양적: 도구개발) / 의사결정(질적 필터→AHP·IPA) | 두 방법이 같은 프로세스로 연결되어야 함 | — |

## 필수 사전 점검
- 결측·역코딩·이상치(±3SD 또는 IQR 1.5배)·정규성(왜도 |2|, 첨도 |7| 관행 — 분야 기준 확인)
- 타당도(EFA/CFA) → 신뢰도(Cronbach α / CR·AVE) → 평균으로 변수 생성
- 상관으로 조감, 다중공선성(r≥.9 또는 VIF≥10)
- 표본 크기: G*Power 사전 계산 [보강]

## 해석 경고
- p값은 효과 크기가 아니다 — 효과크기(η², f², β) 함께 보고
- B는 계산용, β는 보고용
- 부호 반전 → 억제효과, 베타>1·음의 분산 → 헤이우드 케이스
- 결과가 학문적 상식과 충돌하면 설계·데이터부터 재검토(내용 타당도 우선)
