# 글쓰기 기법 분류 체계 (SSOT) v1.0

> 10개 영역 · 97개 기법. `technique-transfer` 스킬의 단일 진실 원천.
>
> **설계 원칙 — 모든 항목은 텍스트에서 탐지 가능해야 한다.**
> "문장이 아름답다" 같은 항목은 넣지 않는다. 세지 못하거나 가리키지 못하는 것은 기법이 아니라 인상이다.
> 항목마다 `탐지 신호`(분석 모드가 찾는 것)와 `적용 지시`(적용 모드가 내리는 명령)를 쌍으로 둔다.

## ID 규칙

`L{영역}-{번호}` — 예: `L2-04`는 문장 영역 4번(종결어미 다양도).
`◆` 표시는 `metrics.py`가 숫자로 계산하는 항목이다. 나머지는 LLM이 판정한다.

## L1 · 어휘

| ID | 기법 | 탐지 신호 | 적용 지시 |
|---|---|---|---|
| L1-01 | 맞춤 명사 | 풀어쓴 곁가지 서술 대신 한 단어로 지목("아침에 잠깐 오는 비"→"소나기") | 서술구 3어절 이상을 명사 하나로 압축할 자리를 찾아 바꿔라 |
| L1-02 | 승자독식 어휘 회피 ◆ | 좋다·나쁘다·예쁘다·이상하다·비슷하다의 빈도가 낮고 분화 어휘가 등장 | 이 다섯 낱말을 찾아 뜻이 갈라지는 어휘로 바꿔라 |
| L1-03 | 고유어 선택 ◆ | 한자어 대신 고유어 비율이 높음(제고→높이다) | 대체 가능한 한자어를 고유어로 바꿔라. 대체어가 없으면 둔다 |
| L1-04 | 전문어 처리 | 분야 용어가 나올 때 즉시 풀어 쓰는가, 그냥 쓰는가 | 원문 방식을 따라라. 풀어 쓰는 글이면 첫 등장에 한 문장 설명을 붙여라 |
| L1-05 | 감각어 배분 ◆ | 시각·청각·촉각·후각·미각 어휘의 비율. 시각 편중인가 균형인가 | 시각 외 감각어를 원문 비율만큼 배치하라 |
| L1-06 | 동사 중심 ◆ | 부사+약동사(정말 빨리 걷다) 대신 강동사(뛰다시피 하다) | 부사를 지우고 동사를 바꿔라 |
| L1-07 | 구체 명사 비율 ◆ | 추상명사(-성·-화·-적) 대 구체명사 비율 | 추상명사를 만질 수 있는 명사로 내려라 |
| L1-08 | 고유명사 질감 | 상표·지명·인명·상호가 실명으로 등장 | 두루뭉술한 지시("어떤 카페")를 실명이나 특정 이름으로 바꿔라 |
| L1-09 | 수치 구체화 ◆ | 여러·상당한·많은 대신 숫자·단위·날짜가 등장 | 흐린 수량어를 숫자로 바꿔라. **모르면 지어내지 말고 질문으로 돌려라** |
| L1-10 | 핵심어 반복 ◆ | 한 낱말이 글 전체에 의도적으로 반복되어 주제를 각인 | 주제어 하나를 정해 원문 빈도만큼 반복하라 |
| L1-11 | 구어·방언·은어 | 입말 어휘, 지역어, 세대어가 섞여 질감을 만듦 | 원문의 입말 수위를 따라라. 과하면 인용 안에만 두라 |

## L2 · 문장

| ID | 기법 | 탐지 신호 | 적용 지시 |
|---|---|---|---|
| L2-01 | 문장 길이 분포 ◆ | 평균 글자 수와 표준편차 | 평균을 ±10% 안으로 맞춰라 |
| L2-02 | 장단 교차 ◆ | 긴 문장 뒤에 아주 짧은 문장이 오는 패턴의 빈도 | 긴 문장 뒤에 10자 이하 문장을 넣어라 |
| L2-03 | 단문·복문 비중 ◆ | 연결어미(-고·-며·-는데·-지만) 개수로 추정 | 복문 비중을 원문에 맞춰 쪼개거나 이어라 |
| L2-04 | 종결어미 다양도 ◆ | -다/-습니다/-네/-지/-까 등의 종류 수와 최장 연속 반복 | 같은 어미가 4회 이상 연속되면 갈아라 |
| L2-05 | 능동·피동 비율 ◆ | -되다·-어지다·-에 의해의 비율 | 피동률을 원문 수준으로 낮춰라 |
| L2-06 | 도치 | 목적어·부사구가 문두로 나오는 문장 | 강조할 성분을 문두로 올려라. 남발 금지 |
| L2-07 | 명사형 종결 ◆ | 체언으로 끝나는 문장("그리고 침묵.") | 결정적 대목 한 곳에만 써라 |
| L2-08 | 병렬·대구 | 같은 구조가 2~3회 반복되는 문장 | 나열은 세 개로 맞추고 구조를 일치시켜라 |
| L2-09 | 삽입구 | 줄표·괄호·쉼표로 부연을 문장 안에 넣음 | 원문이 안 쓰면 부연을 별도 문장으로 빼라 |
| L2-10 | 접속사 절제 ◆ | 그러나·그래서·따라서의 빈도. 접속 없이 잇는가 | 접속사를 지우고도 뜻이 통하면 지워라 |
| L2-11 | 주어 생략 ◆ | '나는·저는'의 반복 여부 | 한국어는 주어를 반복하지 않는다. 원문 빈도만큼만 남겨라 |
| L2-12 | 부호 운용 ◆ | 쉼표·줄표·괄호·말줄임·느낌표의 개수와 종류 | 원문에 없는 부호는 쓰지 마라 |

## 판정 등급

각 기법은 분석 시 네 등급 중 하나를 받는다.

| 등급 | 뜻 | 프로파일 기재 |
|---|---|---|
| **핵심** | 이 글을 이 글답게 만드는 기법. 빼면 다른 글이 됨 | 반드시 기재 + 원문 예시 2개 |
| **사용** | 쓰이긴 하나 결정적이지 않음 | 기재 + 예시 1개 |
| **부재** | 쓰이지 않음. 의도적 회피일 수 있음 | 의도적 회피로 보이면 기재 |
| **해당없음** | 장르상 적용 불가(예: 논문에 L6-03 상징) | 기재하지 않음 |

**핵심 등급은 12개를 넘기지 않는다.** 전부 핵심이면 아무것도 핵심이 아니다.

## 적용 순서 (충돌 시 우선권)

두 기법이 충돌하면 위쪽이 이긴다.

1. **L4 구조** — 구조를 먼저 맞춘다. 구조가 틀리면 문장을 아무리 고쳐도 다른 글이다.
2. **L5 서술·시점** — 인칭과 어조는 글 전체를 지배한다.
3. **L10 시작과 끝** — 독자가 가장 먼저·마지막으로 만난다.
4. **L3 문단** → **L2 문장** → **L1 어휘** — 큰 단위에서 작은 단위로.
5. **L6 형상화 · L7 설득 · L9 정서** — 장르에 따라 셋 중 하나가 주도한다.
6. **L8 리듬** — 마지막. 다른 것을 다 고친 뒤에 다듬는다.

## 금지 사항

- **내용 창작 금지.** 기법을 이식하는 것이지 사실을 옮기는 것이 아니다. 원문의 사건·인물·수치를 사용자 글에 넣지 않는다.
- **문장 복제 금지.** 원문 문장을 그대로 가져오지 않는다. 구조만 가져온다.
- **전면 적용 금지.** 97개를 한꺼번에 적용하지 않는다. 한 번에 3~5개.
- **장르 무시 금지.** 소설 기법을 보고서에 이식하지 않는다. 프로파일에 장르를 명시하고 경고한다.
