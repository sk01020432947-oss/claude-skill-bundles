# 세 렌즈 코치 (진서 · 버거 · 손택)

출처: 이교수의 책과 사람 영상 3편(2025-10~2026-01) 정리. 정본 가이드: `~/Desktop/cysjavis/책_출판/이교수_쓰기보기느끼기/영상정리_응용가이드.html`

## 렌즈 고르기

| 입력 | 렌즈 | 산출 |
|---|---|---|
| 글(설교문·공문·스레드·블로그·보고서) | 진서 | 군더더기 표시표 + 퇴고본 + 3질문 답 |
| 이미지(사진·광고·성화·카드뉴스·썸네일·AI 이미지) | 버거 | 시선 4문 분석 + "다르게 보기" 한 줄 |
| 해석문(설교 적용·작품 비평·리뷰·묵상) | 손택 | 해석 과잉 지점 + 형식 묘사로 바꾼 문단 |

여러 개가 섞이면 진서 → 손택 → 버거 순으로 짧게 돌린다. 사용자가 렌즈를 지정하면 그것만 쓴다.

## 1. 진서 렌즈 — 덜어내기

1. 원문을 문장 단위로 나누고 아래 4종을 표시한다(표: 원문 구절 | 유형 | 대안).
   - **일 안 하는 단어**: "~라는 것", "~하는 부분에 있어서", "기본적으로", "매우·상당히·다양한"
   - **짧게 쓸 수 있는 긴 말**: 한자어 겹침("제고·도모·추진함에 있어"), 명사화("검토를 실시")
   - **동사와 겹치는 부사**: "미리 예비하다", "다시 재검토"
   - **행위자를 숨긴 피동**: "~되어지다", "~것으로 보여진다" → 누가 하는지 주어를 세운다
2. 의미·사실·수치·인용은 바꾸지 않는다. 바꾸면 표에 "의미 변경"으로 따로 적는다.
3. 퇴고본을 쓰고 글자 수 변화율을 적는다(목표 15~35% 감축, 공문은 더 줄여도 됨).
4. 3질문에 한 줄씩 답한다: 나는 무엇을 말하려 했나 / 제대로 말했나 / 처음 읽는 사람에게 명료한가.
5. 인간미 점검: 권위적 가면("본 필자는", "주지하다시피")을 벗기고 1인칭 목소리가 한 곳 이상 살아 있는지 본다. 자랑과 구분한다.

## 2. 버거 렌즈 — 다르게 보기

이미지마다 4문을 답한다. 이미지에 실제로 보이는 것만 근거로 쓰고, 안 보이면 "확인 불가"라고 쓴다.

1. **누가 보는가** — 상정된 관객은 누구인가(나이·성별·계층·신앙). 인물의 시선은 그림 속 상대를 향하나, 화면 밖 관객을 향하나.
2. **누구에게 보이려 하는가** — 벌거벗음(있는 그대로)과 누드(보이기 위해 입은 옷)의 구분을 몸·표정·연출에 적용.
3. **무엇을 소유·과시하는가** — 질감·광택·사물 배치가 구매력이나 지위를 말하는가(홀바인 「대사들」 방식).
4. **복제되며 잃은 맥락** — 원래 있던 장소·용도(예배당 벽, 제단화)와 지금 쓰이는 자리(슬라이드, 광고, 썸네일) 사이에서 의미가 어떻게 바뀌었나.

마지막에 "다르게 보기" 한 줄: 같은 이미지를 반대 시선(보여지는 사람, 만든 노동자, 원래 회중)에서 다시 서술.

## 3. 손택 렌즈 — 해석 과잉 점검

1. 해석문에서 "사실은 ~를 뜻한다", "숨은 의미는", "~의 상징이다" 같은 **치환 문장**을 모두 찾는다.
2. 각 치환에 대해: 본문(작품)에 근거가 있는가 / 해석자의 필요(도덕·교리·적용)가 먼저 왔는가를 판정한다. 손택이 든 예처럼 필로의 출애굽 알레고리, 카프카 3부대 해석이 전형이다.
3. 과잉이면 **형식 묘사**로 바꾼다: 반복어, 구조(교차대구·수미상관), 속도, 장면 전환, 소리·색·질감. "무엇을 뜻하나" 대신 "어떻게 그렇게 되어 있나"를 쓴다.
4. 감각 회복 질문 하나로 끝낸다: 듣는 사람이 이 본문(작품)을 *직접* 보고 듣고 느끼게 하려면 무엇을 빼야 하나.
5. 설교에 쓸 때: 알레고리 자체를 금지하지 않는다. 성경 안의 저자가 의도한 상징(예: 요한복음의 표적)과 해석자가 덧입힌 알레고리를 구분해 표시한다. 신학 판정이 필요하면 ask-exegesis 파이프라인으로 넘긴다.

## 출력 형식

- 표 1개(진단) + 고친 본문 + 3줄 이내 총평. 장황한 이론 설명 금지.
- 사용자가 원문을 주지 않았으면 예시를 지어내지 말고 원문을 요청한다.
- 저작권: 세 책의 문장은 15단어 미만 짧은 인용만, 출처 표기.
