# 박자 맞추기 · Beat sync

레퍼런스 영상과 그 프롬프트를 주고 박자 구조(BPM·마디)를 함께 적으면 모션의 리듬이 레퍼런스를 따라간다. 이 문서는 레시피·카드를 쓸 때 박자 칸을 채우는 법이다.
(근거: AI 투데이 「왜 배운 대로 해도 내 클로드 모션그래픽만 구릴까?」 https://www.youtube.com/watch?v=-YySYOBbhD8&t=361s — 120BPM 7마디, 32박 5구간 구조의 공개 프롬프트)

## 1. 박자 칸 (레시피·카드에 추가)

| 칸 | 예 | 채우는 법 |
|---|---|---|
| `bpm` | 120 | 음악이 있으면 `python3 scripts/bpm.py music.mp3`, 없으면 장면 성격으로 정함(설명 90 · 홍보 120 · 쇼츠 128~140) |
| `bars` | 7 | 장면 수 ÷ 마디당 바뀜 수. 4/4 기준 1마디 = 4박 |
| `change_on` | 매 박 / 매 마디 / 강박만 | 무엇이 바뀌는 단위 |
| `sections` | 32박 → 5구간 | 훅·전개·전환·클라이맥스·로고 같은 구간 경계를 박 번호로 |
| `hold_last` | 1마디 | 마지막 완성 상태(로고·문구)를 읽을 시간 |
| `forbid` | 도형 자르기 금지, 반짝이 금지 | 레퍼런스 프롬프트의 금지 규칙을 그대로 옮김 |

박 타임코드 표는 `python3 scripts/bpm.py --bpm 120 --bars 7`(음악이 있으면 파일 경로와 `--offset` 첫 박 초)로 만든다. 출력 JSON의 `bars[].beats[]`가 키프레임 시각이다.

### beats.json — 실제 음악의 박·강박·강조 지점

음악이 정해져 있으면 균일 격자 대신 실측 시각을 쓴다: `python3 scripts/bpm.py music.mp3 --beats-json > beats.json`
→ `bpm` · `offset`(첫 박) · `beats[]` · `downbeats[]`(마디 첫 박) · `accents[]`(소리가 튀는 상위 8곳). 프롬프트에 파일과 함께 "글자 등장은 `downbeats`, 화면 전환·로고 히트는 `accents`에 맞춰 타이밍을 다시 조정해 줘"라고 붙인다. 템포가 변하는 곡은 `aubio beat music.wav`(brew 설치됨)로 박을 뽑는다.
(근거: Nodi 「클로드 Opus 5.5로 미친 모션그래픽 만드는 방법」 https://www.youtube.com/watch?v=x08U8HJKV0E&t=301s — 배경 음악을 BPM·비트·다운비트·강조 지점으로 beats.json 추출 후 애니메이션 재조정)

## 2. 먼저 묻기 블록 (프롬프트 첫 줄)

레퍼런스 프롬프트처럼 만들기 전에 사용자에게 먼저 묻는다. 묻는 항목은 레퍼런스마다 다르지만 기본은 셋이다.

```
만들기 전에 먼저 물어봐 줘: ① 바꿀 화면·문구 8~12개 ② 주 색 1개 ③ 음악(파일 또는 BPM)
답을 받으면 박자표 위에 화면 순서부터 보여 주고, 내가 확인한 뒤에 렌더해.
```

## 3. 진행 순서

1. 레퍼런스 영상 + 그 프롬프트(있으면) + 소재(제품명·문구·로고)를 준다. 레퍼런스가 없으면 결정표에서 카드 2~3개를 고른다.
2. 위 박자 칸을 채우고 `bpm.py`로 박 타임코드를 뽑는다.
3. 박자표 위에 장면 순서를 먼저 보여 주고 확인받는다.
4. 시안 3개를 병렬로 렌더한다(같은 박자표, 다른 카드나 색).
5. 고친 곳은 장면 하나만 말로 고친다. 세로판은 같은 박자표로 다시 렌더한다.

## 4. 경계

- 레퍼런스에서 빌리는 것은 움직임과 박자 구조까지다. 로고·캐릭터·음원은 복제하지 않는다. 음악은 라이선스를 확인한다.
- 인물 동작이 큰 장면은 이 방식으로 잘 안 된다. 글자·도형·UI 전환에 쓴다.
